# НОМИНАЛ — лендинг по банковским продуктам

Статический сайт: HTML + CSS + два JS-файла плюс один PHP-бэкенд для панели
управления и приёма заявок. Ни сборки, ни зависимостей, ни node_modules.
Заливается на любой хостинг с PHP простым копированием папки.

## Что внутри

```
index.html        главная страница
privacy.html      политика обработки персональных данных
favicon.svg       иконка вкладки
css/style.css     все стили сайта
js/catalog.js     рисует каталог из data.js, подхватывает черновик по ?draft=1
js/app.js         фильтр, аккордеон, форма заявки, анимации
data.js           каталог предложений и тексты сайта — правится через панель
data.php          отдаёт data.js мимо кеша хостинга (панель и сайт грузят его)
api.php           бэкенд: вход, публикация, заявки, телеграм-бот, смена пароля
check.php         страница самопроверки хостинга: ваш-домен.ru/check.php
.htaccess         закрывает служебные файлы, выключает кеш html

panel.html        панель управления (нужен PHP)
panel.css         оформление панели
panel-core.js     ядро редактора каталога — общее для всех витрин
panel-schema.js   описание полей карточки именно этого сайта
publish.js        кнопки «Сохранить на сайт», откат, ZIP
gate.js           экран входа
panel-leads.js    разделы «Заявки», «Уведомления в Telegram», «Пароль»
admin.html        старый адрес панели — просто переадресует на panel.html
img/logos/        логотипы банков и МФО для списка «Готовый логотип»
```

## Локальный запуск

```bash
php -S 127.0.0.1:4580 -t /Users/openclaw/ilya-bank
```

Сайт — `http://127.0.0.1:4580/`, панель — `http://127.0.0.1:4580/panel.html`.

## Панель управления

Адрес: **`ваш-домен.ru/panel.html`**, пароль **`nominal-pz46p13smjs3`**.
Пароль спрашивается при каждом открытии панели; сменить его можно там же,
в разделе «Пароль от панели». Восстановить забытый пароль нельзя — только
задать новый (см. «Если забыли пароль»).

### Каталог

Названия банков и продуктов, цифры, условия, партнёрские ссылки, порядок
карточек, скрытие карточек, разделы (добавить, переставить, удалить пустой),
тексты шапки: название сайта, строка над заголовком, ссылка на Telegram.
Логотип карточки — из готового списка (банки и МФО), свой файл или цветная
плашка с инициалами; цвет плашки задаёт и цвет крупной цифры, сайт сам
затемняет его до читаемого.

Кнопки: «Предпросмотр» открывает сайт с черновиком (видите только вы),
«Проверить» ищет ошибки, «Сохранить на сайт» выгружает правки на боевой сайт,
«Вернуть предыдущую версию» откатывает каталог, «Скачать сайт целиком» —
ZIP-архив. Файлы скачивать и заливать вручную не нужно.

### Заявки

Все заявки с формы сайта — в разделе «Заявки»: имя, дата, телефон (кликабельный),
продукт. Новые с прошлого захода помечаются словом «новая». Кнопка «Скачать
заявки в CSV» отдаёт файл для Excel.

### Уведомления в Telegram

Заявки могут приходить в личку Telegram. Токен бота никуда руками не вписывается:

1. В Telegram открыть `@BotFather`, отправить `/newbot`, придумать имя — он
   ответит токеном вида `1234567890:AAH…`.
2. Вставить токен в панель, раздел «Заявки» → «Уведомления в Telegram», нажать
   «Подключить».
3. Нажать «Получить ссылку для подключения» и открыть её — Telegram сам нажмёт
   «Старт» с одноразовым кодом. С этого момента заявки приходят.

Ссылка одноразовая и живёт 30 минут. Просто найти бота в поиске и нажать
«Старт» нельзя — так посторонний получал бы чужие заявки. Получателей может быть
несколько (каждому — своя ссылка), любого можно убрать кнопкой. Чужие попытки
подключиться панель показывает отдельным предупреждением.

### Если забыли пароль

Зайти на хостинг по FTP или через файловый менеджер, найти файл `.admin-pass`
(лежит в папке `.nominal-private` над корнем сайта либо рядом с `api.php`) и
удалить его — тогда снова работает пароль из этого файла README, вшитый в
`api.php`. Войти и сразу задать новый в панели.

## Что нужно от хостинга

- PHP 8.0 или новее (проверено на 8.3–8.5).
- cURL в PHP — для Telegram. Без него панель и заявки работают, бот — нет.
- Права на запись в папку сайта: панель переписывает `data.js`, метку версии
  в html и файл заявок. Страница `ваш-домен.ru/check.php` покажет, всё ли в порядке.

На GitHub Pages и любом хостинге без PHP панель откроется, но сохранить,
посмотреть заявки и подключить бота не даст — там это только витрина.

## Заливка на хостинг

Скопировать всё содержимое папки в корень сайта (обычно `www/домен` или
`public_html`) по FTP. `README.md` заливать не нужно. Скрытые файлы `.htaccess`
обязательно.

Заявки, токен бота и его служебные файлы api.php сам кладёт в папку
`.nominal-private` **над** корнем сайта — оттуда их не скачать браузером. Если
хостинг не даёт писать выше корня, они лягут рядом с сайтом, и их закроет
`.htaccess`. Проверка: `ваш-домен.ru/leads.csv` не должен открываться.

Панель сама меняет метку `?v=` в html при каждом сохранении, поэтому правки
видны сразу. Если правите файлы руками — поднимите номер в `index.html` и
`privacy.html`, иначе браузеры и хостинг (reg.ru — до 45 суток) отдадут
старую версию.

## Что заменить перед публикацией

1. **Партнёрские ссылки и цифры** — в панели, в карточках. Ставки и лимиты
   сейчас ориентировочные, ставьте только подтверждённые партнёркой.
2. **Реквизиты.** В подвале `index.html` и в разделе 1 `privacy.html` стоят
   нули вместо ИНН/ОГРН. Там же место под `erid`, если размещение маркируется.

## Как всё сделано

Белый холст, плотный чёрный гротеск, синий акцент. Цвет приходит от банков:
у каждого оффера своя плашка с логотипом, от неё же считается цвет крупной
цифры. В первом экране веер из четырёх карт. Контрасты просчитаны под WCAG AA:
весь текст от 4.5:1, рамки и элементы управления от 3:1. Работает с клавиатуры
целиком, есть ссылка «Перейти к основному содержанию», фильтр и форма
озвучиваются скринридером, анимации выключаются при системной настройке
«уменьшить движение». Панель управления вычитана по тем же правилам.
