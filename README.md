# НОМИНАЛ — лендинг по банковским продуктам

Статический сайт: HTML + CSS + один JS-файл. Ни сборки, ни зависимостей, ни node_modules.
Заливается на любой хостинг простым копированием папки.

## Что внутри

```
index.html      главная страница
privacy.html    политика обработки персональных данных
send.php        приём заявок с формы (файл + Telegram)
favicon.svg     иконка вкладки
css/style.css   все стили
js/app.js       фильтр, аккордеон, форма, анимации
```

## Локальный запуск

```bash
php -S 127.0.0.1:4580 -t /Users/openclaw/ilya-bank
```

## Что заменить перед публикацией

1. **Партнёрские ссылки.** В `index.html` найдите блок с рамкой
   `СЮДА ВСТАВЛЯТЬ СВОИ ПАРТНЁРСКИЕ ССЫЛКИ`. У каждой карточки внизу есть ссылка
   `class="card__cta"` — сейчас там `href="#apply"`. Меняете на адрес партнёрки:

   ```html
   <a class="card__cta" id="p1-c" href="https://партнёрка/ссылка"
      target="_blank" rel="noopener sponsored nofollow"
      aria-labelledby="p1-c p1-t">Оформить</a>
   ```

2. **Цифры в карточках.** Ставки, лимиты, кэшбэк и сроки сейчас ориентировочные —
   поставьте реальные из своей партнёрской программы.

3. **Заявки.** Откройте `send.php`, впишите в первые строки токен бота
   (от `@BotFather`) и id чата (от `@userinfobot`):

   ```php
   $TG_TOKEN = '7712345678:AAF...';
   $TG_CHAT  = '123456789';
   ```

   Заявки при этом всё равно дублируются в файл `leads.csv` рядом с сайтом —
   открывается в Excel. Если хостинг без PHP, форма работать не будет: тогда
   в `js/app.js` пропишите `TG_FALLBACK = 'https://t.me/ваш_ник'`, и при ошибке
   отправки посетителю покажут ссылку на Telegram.

4. **Реквизиты.** В подвале `index.html` и в разделе 1 `privacy.html` стоят нули
   вместо ИНН/ОГРН — впишите свои. Там же место под `erid`, если размещение
   маркируется.

## Если правки не видно в браузере

Стили и скрипт подключены с версией: `css/style.css?v=4`, `js/app.js?v=4`.
Браузеры и хостинги кешируют эти файлы (у reg.ru бывает до 45 суток),
поэтому **после каждой правки CSS или JS поднимайте номер** в `index.html`
и `privacy.html`: `?v=4` → `?v=5`. Тогда посетителям сразу прилетит новая версия,
и не придётся объяснять им про Ctrl+F5.

## Заливка на хостинг

Скопируйте всё содержимое папки в корень сайта (обычно `public_html`
или `www`) по FTP. `README.md` заливать не нужно.

После заливки проверьте, что `leads.csv` не открывается по прямой ссылке
(`ваш-домен.ru/leads.csv`). Если открывается — положите рядом `.htaccess`:

```apache
<Files "leads.csv">
  Require all denied
</Files>
```

## Как всё сделано

Тёмно-кофейный текст на тёплом кремовом фоне, крупные заголовки капсом,
матовые стеклянные панели (шапка, карта в первом экране, блок заявки),
одна тёмная полоса для ритма. Контрасты просчитаны под WCAG AA: весь текст
от 4.5:1, рамки и элементы управления от 3:1.

Работает с клавиатуры целиком, есть ссылка «Перейти к основному содержанию»,
фильтр и форма озвучиваются скринридером, анимации выключаются при системной
настройке «уменьшить движение».
